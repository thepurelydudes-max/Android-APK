MLBB COUNTER ASSISTANT — переработка логики подбора пиков
=========================================================

Что изменено в версии 1.0.5:

1. Подбор героев переведён на тот же принцип, который используется в текущем SRC Wild Rift:
   - 60% — сила матчапа против введённого состава;
   - 20% — сколько соперников выбранный герой реально контрит;
   - 15% — tier/meta-компонент;
   - 5% — percentile винрейта на выбранной роли.

2. У MLBB текущая локальная база не содержит отдельной таблицы tier-листа. Поэтому tier-компонент
   получает нейтральное значение 50 и не влияет на сортировку, пока не появится реальный tier-источник.
   Данные не выдумываются и не подменяются винрейтом.

3. Шкала матчапов MLBB (до ±1.5) нормализуется в тот же диапазон -1..+1, что и шкала Wild Rift
   (до ±3). За счёт этого 60-процентный вес матчапа имеет одинаковый смысл в обоих приложениях.

4. Добавлено автоматическое определение вероятных ролей соперников по lanes + role stats / pick rate.
   Для EXP и Mid прямой оппонент получает больший вес, для Jungle — лесник, для Gold/Roam — нижняя пара.
   Остальные соперники всё равно участвуют в расчёте состава.

5. Добавлен guardrail против плохого прямого матчапа: герой с известным тяжёлым проигрышем своей линии
   не поднимается над безопасными кандидатами только из-за дополнительных показателей.

6. Уже выбранные соперником герои исключаются из рекомендаций.

7. Исправлен fallback матчапов: при выбранной роли сначала ищется role-specific строка, затем только
   общая строка role=''. Матчап другой роли больше не может случайно попасть в расчёт.

8. requirements.txt закреплён на Flet 1.0.1 + flet-secure-storage 1.0.1 для текущей Android-сборки.

Проверено на локальной БД проекта: 134 героя, 3226 matchup-записей, 164 role-stat записей.
Расчёт протестирован на EXP / Лес / Мид / Голд / Роум.
