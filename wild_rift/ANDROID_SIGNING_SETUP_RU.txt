WR Counter Assistant — постоянная подпись Android APK
=========================================================

Зачем это нужно
---------------
Android разрешает установить новый APK поверх старого только если:
1. package / applicationId совпадает;
2. новый APK подписан ТЕМ ЖЕ приватным ключом;
3. versionCode новой сборки не ниже установленного.

До версии 3.7.1 GitHub Actions не получал постоянный keystore.
Flet поэтому подписывал release APK временным debug-ключом GitHub Runner.
Каждый новый Runner создавал другой сертификат, из-за чего Android считал
следующую сборку несовместимой с уже установленной.

Начиная с новой схемы сборки
----------------------------
- package ID жёстко закреплён: com.flet.wild_rift
- versionName берётся из wild_rift/VERSION.txt
- versionCode берётся из монотонно растущего GITHUB_RUN_NUMBER
- сборка Wild Rift запрещена без постоянного signing key
- после сборки apksigner проверяет, что APK реально подписан ожидаемым ключом

Одноразовая настройка
---------------------
1. На Windows запустите:
   wild_rift\create_android_signing_key.ps1

2. Скрипт попросит придумать пароль (минимум 6 символов), создаст:
   WR_Counter_Assistant_release.jks

3. Скрипт автоматически скопирует Base64-содержимое keystore в буфер обмена.

4. Откройте репозиторий GitHub:
   Settings -> Secrets and variables -> Actions -> New repository secret

5. Создайте два Repository secret:

   WR_ANDROID_KEYSTORE_BASE64
   Значение: вставить содержимое буфера обмена после запуска скрипта.

   WR_ANDROID_KEYSTORE_PASSWORD
   Значение: тот же пароль, который был введён при создании ключа.

6. Файл WR_Counter_Assistant_release.jks сохранить в надёжном приватном месте.
   НЕ загружать его в публичный GitHub.

После этого
-----------
Первая APK, собранная новым постоянным ключом, потребует ОДИН РАЗ удалить
старую установленную версию, потому что старые APK уже подписаны потерянными
временными debug-ключами.

После установки первой APK с постоянным ключом все дальнейшие версии будут
устанавливаться поверх неё обычным обновлением, без удаления приложения и без
потери локальных данных.

Важно
-----
Никогда не менять:
- package ID com.flet.wild_rift
- signing keystore
- alias farliner

Если потерять keystore, обновить уже установленное приложение тем же package ID
будет невозможно.
