Wild Rift Counter Assistant 3.6.4
====================================

Stability repair — preserve working foundations, change only broken boundaries.

Pick ranking
------------
- The displayed overall score is again the primary and authoritative sort key.
- Matchup, multi-enemy coverage, tier and role win rate still form that score.
- Mirror-lane matchup and hard-loss diagnostics no longer create a hidden ranking
  layer ahead of the displayed score.
- Deterministic component fields remain only as tie-breakers after equal scores.

Item recommendations
--------------------
- WildRiftCore champion+role builds remain the preferred recommendation source.
- If that source is missing/incomplete because of parser/cache/network/rate-limit
  failure, the engine restores the proven WR Pocket champion item-pool builder.
- The fallback is intentionally narrow: only the champion's own approved pool and
  known counter signals are used; it never searches the global shop.
- This prevents the six blank item slots regression while retaining the newer
  role-specific recommendation system whenever its data is healthy.
- Enemy threat adaptation continues to favor practical anti-heal/anti-crit/
  anti-physical/anti-magic/anti-tank answers from the approved champion pool.

Updater
-------
- The 3.6.3 URL-slug champion resolver and duplicate/coverage guards are retained,
  preventing WR Pocket profile identity from collapsing to Zyra.
- Per-image CDN failures are grouped into champion/item media warnings instead of
  turning one source outage into ~200+ user-facing warnings. Full details remain
  inside update-warnings.log.
- Existing WildRiftCore pacing, Retry-After handling and adaptive 429 slowdown are
  preserved; no fast bulk-crawling regression was introduced.

Regression gate
---------------
- APK workflow now syntax-checks the Wild Rift source and runs regression tests
  before building.
- Tests cover score-first ordering, missing-role-build item fallback, preference
  for healthy role builds, the Zyra profile-identity regression, and smoke tests
  against the bundled database.
