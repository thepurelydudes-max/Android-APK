Wild Rift Counter Assistant 3.4.7
====================================

Build recommendation rework:

- The selected role is now passed into recommend_build() and the same role-specific
  matchup matrix used by pick ranking is used when adapting items.
- WR Pocket Build Trends are treated as a categorized champion item pool, not as
  a ready-made six-slot purchase order.
- The base six-slot build is composed by champion archetype, selected role and
  WR Pocket item categories, with one boot maximum.
- Generic enemy counter-item lists are translated into mechanics (anti-heal,
  anti-crit, anti-shield, armor/MR, etc.) and then answered with a compatible
  item from the selected champion's own current pool whenever possible.
- Offensive Physical/Magic items outside the champion's own pool are rejected.
  This prevents examples such as Mortal Reminder on tank Volibear or Chempunk
  Chainsword on AP Mordekaiser.
- The broken upstream champions.damage_type value is no longer used for build
  logic because it currently contains resource types such as Mana/Energy.
- Generic damage hints are inferred from the enemy's current item pool and roles
  and are deliberately low-weight.
- Core identity is preserved: situational answers replace low-priority tail slots
  instead of reshuffling the whole build.
