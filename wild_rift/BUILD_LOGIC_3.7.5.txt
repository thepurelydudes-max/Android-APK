Wild Rift Counter Assistant 3.7.5
====================================

Fresh bundled database and media
--------------------------------
- Every Wild Rift APK build now creates a temporary writable runtime from the
  repository's last-known-good bundled assets.
- The real updater runs before Flet packaging.
- Successfully refreshed wildrift.db and media cache are copied back into
  wild_rift/assets so the APK itself contains the newest available seed.
- New clean installs therefore start with bundled champion portraits, item
  icons, stats/catalog data and cached source data instead of requiring an
  immediate manual "Update data" pass.
- Live-source failures remain non-destructive: updater keeps last-known-good
  tables/files when a source is unavailable.
- Packaging refuses to continue if any final item icon is missing/invalid.
- A bundled_seed_manifest.json records build-time patch, audit counts and
  warnings for later diagnosis.
- Champion portrait audit is reported in build logs; a partial source outage can
  preserve the last-known-good portrait cache rather than breaking the build.

Visual compatibility
--------------------
- 3.7.4 exact pre-optimization champion dropdown visuals are preserved in 3.7.5.
