Wild Rift Counter Assistant 3.7.1
====================================

Patch 7.3 item icon repair
--------------------------
Real Android log still showed six item-media failures:
- Fiendhunter Bolts
- Immortal Boots
- Mercury Boots
- Rapid Firecannon
- Whispering Circlet
- Yun Tal Wildarrows

Root causes
-----------
- The v5 icon pipeline still depended first on predictable CDN paths. Several
  patch 7.3 items exist in the live game/source pages but do not exist at every
  guessed mirror URL.
- "Mercury Boots" is not a separate current item identity. It is an upstream
  shorthand for Mercury's Treads and could survive as a fake standalone DB row.
- stale_kept was treated as failure even when the local file had previously been
  verified from the exact same trusted URL.

Fixes
-----
- Item icon schema bumped to v6 so affected installations retry the repair.
- Added WildRiftCore's WR-native name-addressed items-cn asset path as a third
  cheap candidate after WildRiftMeta and RiftGG.
- If all name-addressed candidates fail, the updater now opens the exact
  WildRiftCore and WildRiftMeta item page, verifies the page H1 matches the
  requested canonical item, extracts the actual item image src, rejects
  placeholders/SVGs, and retries that exact URL.
- "Mercury Boots" and "Mercury Treads" canonicalize to Mercury's Treads.
- Added an offline-safe SQLite alias migration that merges old Mercury Boots
  records and build/media references into Mercury's Treads without losing
  cached data.
- A stale_kept item is accepted only when the cache manifest proves the local
  image came from the exact same currently trusted URL. Old/untrusted cached
  artwork is still rejected and cleared.
- Item source metadata now accurately distinguishes WR Pocket catalog data from
  the separate item-art sources.

Regression tests
----------------
- Locks Mercury Boots -> Mercury's Treads canonicalization.
- Ensures reported patch 7.3 failures receive a WR-native items-cn candidate.
- Tests exact WildRiftCore page image extraction for Fiendhunter Bolts.
- Tests that placeholder SVG artwork is rejected.
- Tests item alias migration preserves media identity.
