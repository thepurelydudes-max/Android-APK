Wild Rift Counter Assistant 3.6.8
====================================

Fixes from real Android update log
----------------------------------
- Fixed the real Norra/Zyra collision reported by update-warnings.log.
- Champion profile URLs now resolve against exact champion IDs only; fuzzy or
  localized display names can no longer turn /champions/norra into Zyra.
- The current WildRiftMeta roster supplements newly released WR champions that
  are missing from the structured ry2x feed. Norra is therefore added as Norra
  instead of being skipped or misidentified.
- WR-exclusive champion portraits fall back to the champion's WildRiftMeta icon
  when PC Data Dragon does not contain that champion.

WildRiftCounter stability
-------------------------
- Added paced requests and retries for RemoteDisconnected/ConnectionError,
  HTTP 429 and transient 5xx responses.
- A failed counter-item refresh still does not replace the last known-good
  counter-item table.

Item artwork repair
-------------------
- WR Pocket is no longer authoritative for final item artwork.
- Confirmed wrong bundled 3.6.5 artwork for Kaenic Rookern and Sundered Sky.
- Current icons are fetched from name-addressed WildRiftMeta first, with a
  second independent mirror as fallback.
- Possessive asset slugs are fixed: Mercury's Treads -> mercurys-treads,
  Randuin's Omen -> randuins-omen, etc.
- Item icon schema v5 forces one controlled repair pass on old installations.
- The full-catalog repair is paced so the image source is not hit with a burst.

Current patch boots
-------------------
- Removed the obsolete boot-renaming layer that converted current patch boots
  into historical upgrade names.
- Mercury's Treads remains Mercury's Treads; Plated Steelcaps remains Plated
  Steelcaps; Boots of Mana remains Boots of Mana when current role-build sources
  publish those names.
- Source-declared boot slots are promoted to usable Upgraded/Boots catalog rows
  even if an older WR Pocket snapshot labelled them as intermediate.
- Missing item art never falls back to the WR Counter Assistant app logo; the UI
  shows a neutral missing-image marker instead.

Regression coverage
-------------------
- Reproduces and blocks the Norra -> Zyra profile collision.
- Tests WildRiftCounter connection retry behavior.
- Tests Norra roster supplementation and portrait URL.
- Locks current boot identity.
- Locks correct possessive item-icon URL generation.
- Existing ranking, item-build, tier-integrity and cache regression tests remain.
