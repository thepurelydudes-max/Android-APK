Wild Rift Counter Assistant 3.6.7
====================================

Item artwork source repair
--------------------------
- Confirmed real data corruption in the packaged 3.6.5 item cache:
  Kaenic Rookern was stored as wrpocket lol_fjdp.webp (wrong artwork),
  Sundered Sky was stored as wrpocket lol_kefd.webp (wrong PC/generic artwork).
- The bundled database also contained 10 upgraded item icons served from
  WR Pocket local /assets/img/items paths instead of the normal WR EquipIcons
  source, including a duplicate URL shared by Ardent Censer and Stormsurge.
- WR Pocket is no longer authoritative for item artwork. It remains a source for
  build trends/stats/item text only.
- Item icons now use two independent, name-addressed Wild Rift icon mirrors:
  WildRiftMeta first, RiftGG/WildPick second.
- The cache accepts an icon only after media_cache validates the downloaded
  bytes as an actual image.
- Icon schema bumped to v5, forcing a repair pass on existing installations.
- When a trusted icon URL differs from a previously cached WR Pocket URL, the
  old image is replaced. If both trusted mirrors fail, the stale icon_path is
  cleared instead of silently keeping a wrong image.

Boot identity
-------------
- Legacy/mid-tier boot names from upstream build text are normalized to the
  completed boot item before missing role items can be seeded.
- Mercury's Treads -> Chainlaced Crushers
- Plated Steelcaps -> Armored Advance
- Berserker's Greaves -> Gunmetal Greaves
- This prevents an intermediate boot from being inserted as a fake Upgraded
  item and later displaying no icon.

Android UI
----------
- Item cards/previews/details no longer fall back to the Wild Rift application
  logo when artwork is missing.
- Items display only a successfully cached trusted icon.
- If an icon cannot be verified, the UI shows a neutral missing-image marker,
  making the failure visible without misidentifying the item.

Regression coverage
-------------------
- Tests lock the exact trusted icon URLs for Kaenic Rookern, Sundered Sky and
  Mercury's Treads.
- Tests lock legacy boot -> completed boot normalization.
- The bundled Upgraded catalog is checked so two different item names cannot
  collapse to the same name-addressed primary icon URL.
