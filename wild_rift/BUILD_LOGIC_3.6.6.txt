Wild Rift Counter Assistant 3.6.6
====================================

Android log access
------------------
- Added a "Скопировать лог" / "Copy log" button next to "Обновить данные".
- The button copies the complete latest update-warnings.log text directly to
  the system clipboard using Flet 1.0 Clipboard service.
- If no warning log exists, the app reports that there is nothing to copy.
- After a clean update with zero warnings, an old update-warnings.log is deleted
  so the button can never return stale errors from a previous update.
- The button label follows the current RU/EN interface language.
