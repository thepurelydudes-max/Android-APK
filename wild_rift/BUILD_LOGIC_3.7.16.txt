Wild Rift Counter Assistant 3.7.16
=====================================

Ranking display clarity
-----------------------
The recommendation order itself is unchanged.

WRCA intentionally ranks a role primarily by exact draft matchup_sum, then by
coverage_count / positive strength / negative exposure. The documented 60/20/15/5
meta score (matchup + coverage + tier + win rate) is only a later tie-breaker.

Previously the card displayed that secondary composite as "Оценка / Score".
That could make a lower-ranked champion appear to have a larger "score" than the
champion above it, even when the ranking was working exactly as designed.

3.7.16 therefore changes only the visible card summary:
- "Оценка / Score" is no longer shown as if it were the sorting authority.
- Cards show the primary Matchup sum.
- Cards show Coverage as positive matchups / selected enemies.
- Tier and win rate remain visible.
- The internal 60/20/15/5 meta score is retained unchanged for late tie-breaking.

This preserves recommendation accuracy while making the visible numbers agree
with the reason the list is ordered.
