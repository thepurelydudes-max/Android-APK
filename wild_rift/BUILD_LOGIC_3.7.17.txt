Wild Rift Counter Assistant 3.7.17
=====================================

Rank-aligned Draft Score
------------------------
The visible "Оценка / Score" now measures how well a champion fits the selected
enemy draft using the same two leading authorities that determine list order:

    Draft Score = clamp(50 + 3 * matchup_sum + 0.4 * coverage_count, 0, 100)

Why this formula
----------------
- matchup_sum is the primary ranking authority.
- coverage_count is the second ranking authority.
- One full matchup_sum point is worth 3.0 score points.
- The entire possible 0..5 coverage spread is worth only 2.0 points.
  Therefore coverage can break equal matchup sums but can never overturn a
  genuine +1 matchup_sum advantage.
- The score is clamped to 0..100 for a stable UI scale.

Meta strength remains available internally
------------------------------------------
The previous 60/20/15/5 composite (matchup / coverage strength / tier /
win-rate) is preserved as meta_score and remains a late deterministic
tie-breaker. It no longer drives the user-facing score, so a lower-ranked
champion cannot look numerically "better" merely because its tier/win-rate is
higher.

Recommendation order
--------------------
The recommendation algorithm itself is not weakened or reordered:
1. matchup_sum
2. coverage_count
3. raw positive strength
4. fewer negative matchups
5. lower negative strength
6. meta_score
7. remaining deterministic tie-breakers

The change makes the displayed number explain the existing recommendation
logic instead of competing with it.
